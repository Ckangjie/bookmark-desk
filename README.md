# 书签管家 BookmarkDesk

Chrome / Microsoft Edge 的 Manifest V3 扩展。用独立标签页搜索和批量管理扩展的本地书签库。

## 构建与加载

1. 在项目目录运行 `pnpm install` 和 `pnpm build`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发人员模式。
3. 点击「加载已解压的扩展程序」，选择项目下的 `dist` 目录。
4. 点击扩展图标，或按默认快捷键 `Alt+Shift+B` 打开工作台。快捷键可在浏览器的扩展快捷键页面修改。
5. 点击「同步系统书签」导入当前浏览器配置文件里的 HTTP(S) 书签。

## 数据行为

同步使用书签的直接父文件夹作为分类，并按规范化后的完整 URL 去重。同步会补充当前库中没有的书签，因此原生收藏夹中仍存在的项目可以再次导入。

移动分类作用于扩展本地库。删除默认只移除本地副本，开启工作台顶部的「同时删除浏览器原始书签」后，单条和批量删除都会在确认后移除当前浏览器中同一网址的所有原始书签。同步删除设置、分页大小和排序方式保存在扩展存储中。网站图标通过浏览器的 favicon 接口加载，失败时显示默认图标。书签数据没有上传流程。

表头复选框选择当前页，跨页可以继续勾选。改变搜索词或分类会清空选择。关键字检索按标题和网址进行子串匹配。类别和时间排序使用 IndexedDB 索引，查询结果按页读取。

健康度检测、规范化链接合并和 HTML/JSON 备份迁移属于 PRD 后续版本。
